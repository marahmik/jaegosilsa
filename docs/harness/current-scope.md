## MUST
- 한 외부 사이트의 고정 POS XLSX 양식·Sheet1·전체 62,080행 규모를 지원하고 현매장 재고 하나만 기준으로 사용한다.
- 상품명에서 규칙에 맞는 품번·색상을 정리하고, 예외 상품은 원문 및 확인 필요 표시로 보존한다.
- 옵션명을 옵션/사이즈 원문으로 표시한다.
- 엑셀 바코드 열과 PC 키보드형 스캐너 입력을 직접 매칭한다. 0재고 제품도 매칭 대상이다.
- 스캔 1회당 1개 누적하고 오스캔 취소 및 수량 수정을 지원한다.
- 실물−기준 차이와 원본 재고의 음수·양수 상태를 별도로 확인한다.
- 미등록 스캔은 집계하지 않고 화면 경고와 오류 음성을 출력한다.
- 각자 브라우저에 저장하여 새로고침 후 이어서 실사한다.
- 결과를 화면에서 확인하고 XLSX로 다운로드한다.
- 잘못된 입력과 새 파일 교체로 기존 기록이 조용히 손실되지 않게 한다.
- 정상 스캔의 수량 저장 성공 후 짧은 비프음으로 등록 완료를 알립니다. 오류·수정·취소에는 성공음을 내지 않습니다.

- 기준 수량은 현매장 재고 한 열이다. 창고 및 타 매장 열을 합산하지 않는다.
- 바코드는 숫자로 변환하거나 대소문자를 변경하지 않는다. 스캐너 종료 신호·입력란 외곽 공백만 입력 경계에서 처리한다.
- 원본 상품명·옵션명을 보존하며 규칙 밖 제품의 품번·색상 및 사이즈를 추측하지 않는다.
- 공동 실사·자동 동기화·외부 사이트 원본 수정은 하지 않는다.
- 샘플 원본은 사용자 Downloads 경로에서 읽기만 하고 저장소에 복사하거나 커밋하지 않는다.
- 기존 Windows 하네스 실패를 앱 검증 성공으로 대체하지 않는다. 앱 자체의 검증과 실제 브라우저·장비 검증을 수행한다.
